# LifeScribe v0.2.5

A housekeeping release: the Mac build, an open-source license, and a proper README. The app itself behaves the
same as 0.2.4 on Windows.

## macOS

- LifeScribe is now available for Mac: `LifeScribe_0.2.5_universal.dmg` runs on both Apple Silicon and Intel Macs
  (macOS 11 or later). Open the `.dmg` and drag LifeScribe to Applications.
- The app is **not code-signed or notarized**, so macOS warns "Apple could not verify this app" the first time you
  open it. On macOS 15 (Sequoia) or later, open **System Settings → Privacy & Security** and click **Open Anyway**
  next to LifeScribe. On earlier versions, right-click the app and choose **Open**. You only need to do this once.
- The Mac window opens at 1280 × 800.
- It is built by a GitHub Actions workflow (`.github/workflows/macos-build.yml`) and hasn't been tested on a Mac
  yet. Please report anything odd.
- Data folders aren't portable between Windows and Mac: story images store the full file path of the computer they
  were written on. A Mac install is its own separate biography.
