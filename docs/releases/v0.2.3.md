# LifeScribe v0.2.3

## Removed: AI curation

The optional AI feature is gone, so the app never sends your text anywhere.

- The **AI Curation** card (Anthropic API key) is removed from Settings.
- The **Curate with AI** panel is removed from the import review page.
- Any API key saved by an earlier version is deleted from the app's local storage the first time you start this
  version.
- The Anthropic library is no longer part of the app.

## Changed

- The import review page is now **Review Imported Items** (it was "Review AI Suggestions"). It still lists the
  stories, milestones and career entries found in your Facebook, Instagram and LinkedIn archives so you can accept
  or reject each one. Nothing is added to your biography until you accept it.

## Upgrading from 0.2.2

No database changes. Nothing else needs doing.

## Under the hood

- Removed `ai-curator.ts` and the `@anthropic-ai/sdk` dependency; docs updated.
- 124 automated tests pass.
