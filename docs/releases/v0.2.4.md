# LifeScribe v0.2.4

## New look: the official LifeScribe logo

- The sidebar now shows the official LifeScribe logo (as on lifescribe.us) at full width, with "Biography"
  underneath.
- The app icon, the desktop and taskbar icon, the window icon, the installer icons and the browser favicon all use
  the official mark, a book with a quill and infinity loop on a rounded teal square.
- The logo artwork and the script that generates every icon size are in the `branding/` folder.

## Window

- The window now opens at 1280 × 1386, so the whole Overview page fits without scrolling. You can still resize it
  down to 900 × 600.

## Profile

- Removed the **Tagline** and the **Profile photo**. Both were left over from the website: the tagline only showed
  under the title on the Read-mode home page, and the profile photo wasn't shown anywhere.
- **Subject identity** is now the first section of the Profile page, ahead of General (title and bio) and the
  banner.

## Settings

- Removed the **Photo library** button. It was a one-time fix for old photo links, and every image is stored in
  the app's data folder now.
- Removed the **Back up now** button. **Data location** now explains how to back up: close the app and copy the
  data folder to another drive. The user guide covers the same steps.

## Upgrading from 0.2.3

The first launch makes one small database change: it removes the unused tagline and profile photo from your
profile. Your title, bio, banner and name are untouched, and the old profile photo file stays in your media folder.
If you like, copy your data folder first.
