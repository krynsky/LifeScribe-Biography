What shape should the Reader View take?

This is the foundational choice — it decides navigation, chrome, and how "immersive" reading feels vs. staying inside the current app.

A

Full-screen immersive mode

A "Read Biography" button replaces the entire app shell with a distraction-free book-like view: cover page, chapters/timeline nav, story pages, photo spreads. The editor sidebar (Stories, Gallery, Settings...) disappears entirely. One click "Exit" returns to the editor.

B

New section inside the existing app

A "Read" item added to the current sidebar nav (alongside Stories, Gallery, Timeline...). Clicking it swaps the main content area into a polished reading layout, but the app's sidebar and chrome stay visible the whole time — reading is just another page, not a separate mode.

C

Per-item "Preview" only

No dedicated reader mode at all. Instead, every story/album/etc already has a "Preview" button that shows how that ONE item looks when read (like AlbumPage's read-only look, but for stories/milestones too). No unified whole-biography reading experience — just item-level previews.

My recommendation: A — full-screen immersive mode. It matches "read the biography like a book," gives room for a real cover/timeline/chapter experience, and is the natural foundation the static-site and PDF exports (sub-projects #3/#4) can reuse almost directly. B is a reasonable fallback if you want reading to feel more like "just another tab." C is scoped too small — it doesn't give a whole-biography experience.
